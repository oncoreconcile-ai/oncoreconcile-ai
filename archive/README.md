# Archive

This folder contains historical datasets, intermediate artifacts, and experimental resources retained for reproducibility and future development.

These files are not required for normal application execution.

## Contents

### data_v2

Historical alias-generation resources used during development of OncoReconcile AI.

Includes:

- Gene alias generation inputs
- Variant alias generation inputs
- Candidate gene-variant resources

Retained for:

- Reproducibility
- Future benchmark expansion
- Future ontology enrichment
- Alias dictionary improvement

The active production datasets are located under the main `data/` directory.
